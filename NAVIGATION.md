# Навигация приложения

Референс выбран Юрием 28 октября 2026: раскрытая и свёрнутая панель приложения «Конструктор приложений». Компонент `AppShell` находится в `packages/react/src/app-shell` и входит в `@ykurilov/ds-react` с версии 0.4.0.

## Единый стандарт

На компьютере панель занимает 264 px, в свёрнутом состоянии — 68 px. Кнопка сворачивания находится вверху самой панели: справа от названия, а после сворачивания — над значками. Значки разделов сохраняют свои вертикальные координаты. Подписи исчезают, выбранный раздел остаётся выбранным. У значков остаются названия для экранного диктора и подсказки при наведении.

Рабочая поверхность светлая (тёмная в тёмной теме), со скруглением `--yk-radius-studio-panel`, расположена на фоне `--yk-sidebar`. Освободившееся место получает рабочая область. Переход длится 180 мс; при `prefers-reduced-motion` он мгновенный.

Список разделов прокручивается независимо. Верх панели и нижний блок аккаунта остаются на месте. Нижний блок приложение передаёт через `footer(collapsed)`: в раскрытом виде — аватар и подпись, в свёрнутом — аватар. Данные аккаунта и пункты его меню принадлежат приложению.

На ширине до 700 px панель скрыта. Кнопка в шапке открывает её слева поверх содержимого, без изменения ширины рабочего экрана. Панель модальная: фон недоступен для клавиатуры; Escape, выбор раздела, крестик и нажатие на фон закрывают её. Фокус возвращается кнопке открытия. Состояние компьютерной панели сохраняется при переходе к мобильной раскладке.

## Цвет выбранного раздела

С `@ykurilov/ds-react@0.5.0` выбранный пункт имеет фон `--yk-surface-3` и цвет текста/значка `--yk-text`. При наведении на невыбранный пункт фон `--yk-surface-2`; выбранный сохраняет свою плашку. Правило общее для полной панели, значков и мобильного меню, в обеих темах. Переопределение CSS в приложении не требуется.

Компонент `Tabs` также использует серую плашку по умолчанию, без оранжевой нижней черты. Оранжевый фокус клавиатуры сохраняется. После обновления удалите свои цветовые переопределения `.yk-app-shell__item[aria-current=page]` и вкладок, если они повторяли этот стандарт; параметры раскладки приложения оставьте.

## Подключение

Приложение передаёт `brand`, массив `navigation` с `id`, `label`, `icon`, `active` и `href` либо `onSelect`, содержимое шапки `header`, блок аккаунта `footer` и основное содержимое как `children`. Иконки — Phosphor. Роутер, права доступа и состав разделов остаются у приложения. Кнопки навигации не подменяют нативное поведение ссылок. Ссылку роутера (например, `Link` из Next.js) передают в `linkComponent`, иначе ссылки — обычные `<a>`. Счётчик раздела — `badge: { value, label }`: число видно справа от подписи, в свёрнутом виде — в углу значка, `label` читает экранный диктор.

По умолчанию панель раскрыта. Для контролируемого состояния служат `collapsed` и `onCollapsedChange`; для начального — `defaultCollapsed`. Необязательный `storageKey` сохраняет выбор пользователя. Ключ задаёт приложение, чтобы оболочки одного домена не перезаписывали друг другу предпочтения; без ключа записи в localStorage нет. Недоступное хранилище не мешает работе.

Оболочке отводят высоту через родителя, например `height: 100dvh; min-height: 0`. У неё одна рабочая область `main`: вложенный экран не должен создавать второй `main`. `StudioLayout` остаётся композицией рабочего экрана с журналом; при вложении в `AppShell` его `navigation` не передают.

Подписи действий локализуются через `labels`, имя навигации — через `navigationLabel`. Длинные подписи сокращаются, не расширяя панель.

Существующие приложения автоматически не меняются. Новые приложения используют этот компонент вместо собственной реализации раскрытия панели. Перед публикацией проверить обе темы, мобильную панель, длинный список, управление с клавиатуры и сохранение выбранного раздела.

## Проверка образца

После запуска референса: `pnpm --dir apps/showcase navigation:check`. Chromium и WebKit проверяют неподвижные координаты значков, обе темы, мобильное открытие и закрытие, возврат фокуса, изоляцию фона, длинный список и закреплённый аккаунт. Полная клавиатурная навигация WebKit проверяется через Option+Tab. Это headless-проверка движков, не проверка физического iPhone.

## Меню аккаунта внизу панели

Передайте `Menu` непосредственно из `footer(collapsed)`, а кнопку аккаунта - в `Menu.trigger`. `AppShell` растягивает обёртку и кнопку на ширину списка разделов: в раскрытом виде до обоих краёв списка, в свёрнутом до 48px. На телефоне действует та же композиция. Глобальный `Menu` остаётся строчным в остальных местах. Дополнительный CSS для `.yk-menu-anchor` и `w-full` у кнопки здесь не требуется. Если между `footer` и `Menu` приложение добавляет свою обёртку, управление её размером остаётся у приложения.

Кнопка и подпись принадлежат приложению: при `collapsed=true` оставьте аватар и доступное имя кнопки; в раскрытом состоянии добавьте имя/почту. Список пунктов, команды и их обработчики также задаёт приложение.

Для меню аккаунта оставьте `Menu.align` незаданным: автоматика выбирает сторону по доступному месту. Жёсткое `align="end"` привязывает правый край меню к правому краю кнопки и в узкой левой панели может увести меню за экран. Если приложение задаёт выравнивание вручную, оно также отвечает за эту раскладку.

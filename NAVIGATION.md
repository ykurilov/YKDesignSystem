# Навигация приложения

Стандарт — вариант A, утверждён Юрием 8 ноября 2026: плоская панель на фоне `--yk-sidebar`, как у Gemini. Компонент `AppShell` из `@ykurilov/ds-react` (вид A — с версии 0.6.0). Приложение передаёт только данные, внешний вид и поведение задаёт компонент. Живой пример — `explorations/app-navigation`, прототип и архив вариантов B и C — `explorations/sidebar-a|b|c`.

## Из чего состоит панель

**Верх.** Логотип и название слева (название 14 px, насыщенность 600: «Живые лидмагниты» помещается в панель 264 px; длинное обрезается «…», полное — в `title`). Справа поиск (если передан `onSearch`) и кнопка сворачивания. В свёрнутом виде остаётся только кнопка сворачивания: значки ниже не сдвигаются.

**Главное действие** (`primaryAction`, необязательно). Серая плашка над разделами. В свёрнутом виде — значок с подсказкой.

**Разделы** (`navigation`). Строки 40 px со значком. Не прокручиваются, если есть группы.

**Группы** (`groups`, необязательно). Единственная прокручиваемая часть. Подзаголовок — мелкий моноширинный капс. Строки 36 px. Два вида, вид задаёт приложение:
- разделы с `iconsWhenCollapsed: true` — «Обучение», «Финансы» в кабинете. В свёрнутом виде остаются значками без подзаголовков;
- списки — проекты, история чатов. В свёрнутом виде скрыты. Пункт без `icon` — строка без значка, как строка чата.

`visibleCount` прячет лишнее под «Ещё N», повторное нажатие — «Свернуть». Выбранный пункт под «Ещё» не прячется: группа раскрывается сама.

**Низ.** Блок аккаунта (`account`): аватар, имя, вторая строка; справа шестерёнка (если передан `onSettings`). Нажатие на аватар открывает меню аккаунта — пункты задаёт приложение. В свёрнутом виде остаётся только аватар.

## Правила

**Главное действие — только у приложения с одним постоянным повторяющимся действием**, которое главнее остальных: «Новый чат» в чате с агентом. В кабинетах, админках и планировщиках его нет, разделы стоят сразу под верхом.

**Три вида блока аккаунта**, по умолчанию «Почта»:
- «Почта» — `email`, поле `show` не задавать;
- «Тариф» — `plan` и `show: "plan"`, только где тарифы есть;
- «Только имя» — `show: "name"`.

Если для выбранного вида нет данных, остаётся одно имя.

**Тема — только в настройках**, по умолчанию «Как в системе». Отдельной кнопки темы нет: ни в панели, ни в шапке, ни быстрым пунктом меню аккаунта. Шестерёнка и пункт «Настройки» в меню аккаунта открывают настройки, в них — готовая часть `ThemeSettings` («Как в системе / Светлая / Тёмная»). Выбор запоминается.

## Размеры и поведение

Ширина 264 px, свёрнутая 68 px. Центр значков на x = 34 px в обоих видах. Выбранный пункт — плашка `--yk-surface-3`, текст `--yk-text`, значок `fill`; наведение — `--yk-surface-2`. Новое — оранжевая точка `hasNew`, счётчик — `badge: { value, label }`. Экранный диктор слышит и то и другое. Длинные подписи обрезаются «…», в свёрнутом виде у значков есть подсказки. Переход 180 мс, при `prefers-reduced-motion` мгновенный. Рабочая область плоская и отличается от панели только фоном `--yk-bg`.

До 700 px панель скрыта. Кнопка в шапке открывает её слева поверх содержимого (ширина `min(300px, 86vw)`), фон затемняется. Панель модальная. Escape, нажатие на фон, крестик, выбор пункта, поиск, шестерёнка или пункт меню аккаунта закрывают её. Фокус возвращается кнопке открытия.

## Подключение

```tsx
import { AppShell, Dialog, ThemeSettings, type AppNavigationGroup } from "@ykurilov/ds-react";

<AppShell
  brand={{ label: "Агент", logo: <Sphere size={24} label="Агент" /> }}
  primaryAction={{ label: "Новый чат", icon: NotePencilIcon, onSelect: newChat }}   // только для чата
  navigation={[{ id: "home", label: "Обзор", icon: HouseIcon, active: true, href: "/" }]}
  groups={[{ id: "recent", label: "Недавние", visibleCount: 20,
    items: chats.map(c => ({ id: c.id, label: c.title, active: c.id === current, onSelect: () => open(c.id) })) }]}
  onSearch={openSearch}
  account={{ name: user.name, email: user.email, menu: [{ label: "Настройки", onSelect: openSettings }, "separator", { label: "Выйти", onSelect: logout }] }}
  onSettings={openSettings}
  storageKey="my-app-nav"
>
  {page}
</AppShell>

<Dialog open={settingsOpen} onClose={closeSettings} title="Настройки"><ThemeSettings /></Dialog>
```

Пункт навигации и группы — `href` (ссылка) или `onSelect` (кнопка). Ссылку роутера (например, `Link` из Next.js) передают в `linkComponent`, иначе ссылки — обычные `<a>`. Роутер, права доступа и состав разделов остаются у приложения.

Чтобы сохранённая тема применилась до первой отрисовки, без вспышки, в `<head>` ставят `<script>{themeScript()}</script>`. Скрипт заодно красит строку статуса браузера: берёт фон действующей темы и ставит его в `<meta name="theme-color">` (при выборе темы и при смене системной). Саму meta добавляет приложение, например `<meta name="theme-color" content="#FFFFFF" />`; без неё скрипт ничего не создаёт, а meta с атрибутом `media` не трогает.

В серверном `layout.tsx` Next.js (App Router) `themeScript` берут из серверного подпути: основной вход пакета помечен `"use client"`, и вызов оттуда на сервере падает.

```tsx
import { themeScript } from "@ykurilov/ds-react/theme-script";

// <html lang="ru" suppressHydrationWarning>
//   <head><script dangerouslySetInnerHTML={{ __html: themeScript() }} /></head>
``` Ключ хранения по умолчанию `yk-theme`; свой — `storageKey` у `ThemeSettings`, `useThemePreference` и `themeScript`, одинаковый у всех трёх.

Свёрнутость: по умолчанию панель раскрыта. `collapsed` и `onCollapsedChange` — для управляемого состояния, `defaultCollapsed` — начальное. `storageKey` запоминает выбор; без ключа записи в localStorage нет.

Оболочке отводят высоту через родителя, например `height: 100dvh; min-height: 0`. Рабочая область одна — `main`. Подписи кнопок переводятся через `labels`, имя навигации — `navigationLabel`.

## Прежний способ: свой `footer`

`footer(collapsed)` продолжает работать, если `account` не передан. `Menu` прямо в `footer` и его кнопка растягиваются на ширину строки. Для новых приложений — `account`: так низ одинаков во всех приложениях.

## Проверка образца

После запуска референса (порт 5967): `pnpm --dir apps/showcase navigation:check`. Chromium и WebKit проверяют неподвижные значки при сворачивании, главное действие, группы и «Ещё», блок аккаунта, отсутствие кнопки темы вне настроек, выбор темы в настройках (системная → тёмная → запомнилась → системная), мобильное открытие и закрытие, возврат фокуса, изоляцию фона, длинный список и закреплённый низ. Это headless-проверка движков, не физического iPhone.

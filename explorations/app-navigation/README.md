# Референс навигации приложения

Использует настоящий `AppShell` из исходников `ds-react`. Раскрытая панель, иконки и мобильная шторка; светлая и тёмная темы. Образец выбран Юрием в приложении «Конструктор приложений».

Из корня YKDesignSystem:

```sh
pnpm --dir apps/showcase exec vite ../../explorations/app-navigation --config ../../explorations/app-navigation/vite.config.mjs --host 127.0.0.1 --port 5967
```

Открыть http://127.0.0.1:5967/. Кнопки справа над примером переключают тему и мобильный вид. При настоящей ширине до 700 px мобильная раскладка включается сама. Пример не требует Agent Chat SDK и не обращается к API.

Правила подключения - [NAVIGATION.md](../../NAVIGATION.md). Основное содержимое, список разделов и данные аккаунта здесь демонстрационные.

# Референс навигации приложения · вариант A

Настоящий `AppShell` из исходников `ds-react` в стандартном виде A: главное действие «Новый чат», разделы со значками, группа «Проекты» с «Ещё N», история чатов «Недавние» строками без значков, блок аккаунта (вид «Почта»), шестерёнка. Шестерёнка и пункт «Настройки» в меню аккаунта открывают настройки с `ThemeSettings`. Отдельной кнопки темы нет.

Из корня YKDesignSystem:

```sh
pnpm --dir apps/showcase exec vite ../../explorations/app-navigation --config ../../explorations/app-navigation/vite.config.mjs --host 127.0.0.1 --port 5967
```

Открыть http://127.0.0.1:5967/. Кнопка справа над примером включает вид телефона. При настоящей ширине до 700 px мобильная раскладка включается сама. Адрес `?long` даёт длинный список разделов без групп, `?theme=dark` — тёмную тему для снимков. Пример не требует Agent Chat SDK и не обращается к API.

Правила подключения — [NAVIGATION.md](../../NAVIGATION.md). Данные здесь демонстрационные.

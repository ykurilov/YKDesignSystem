# Сайдбар · вариант C — плотная панель рабочего приложения

Структура как у Gemini, но для приложений, где разделов и данных много: админки, кабинеты, планировщики. Тот же стандарт подходит и чату (переключатель «Чат и разделы / Только разделы»).

Запуск из корня YKDesignSystem:

```sh
pnpm --dir apps/showcase exec vite ../../explorations/sidebar-c --config ../../explorations/sidebar-c/vite.config.mjs --host 127.0.0.1 --port 5283
```

Открыть http://127.0.0.1:5283/. Переключатели вверху: тип приложения, состояние (раскрыто / свёрнуто / телефон), вторая строка аккаунта, тема. Снимки: `node shoot.mjs` → `screenshots/`.

Компонент — `WorkShell.tsx` + `work-shell.css`, только токены «Одуванчика».

## Что жёстко одинаково

**Верх.** Логотип и название слева, справа поиск и кнопка сворачивания. Поиск заменяет строку названия полем ввода и фильтрует все группы сразу, включая историю; Enter открывает первое совпадение, Esc закрывает.

**Главное действие.** Серая плашка во всю ширину с подсказкой клавиши справа. В свёрнутом виде — серый квадрат со значком.

**Середина** — единственная прокручиваемая часть. Группы с мелкими серыми подзаголовками моноширинным капсом. Строки 36 px (чаты 32 px, на телефоне 44 px под палец).

**Низ.** Аватар и две строки, справа шестерёнка; над низом тонкая черта. Клик по аватару — меню аккаунта. Вторая строка:
- тариф — только если приложение его передало (моноширинный капс);
- иначе почта (основной случай, тарифов в большинстве приложений нет);
- нет ни того, ни другого — одно имя по центру аватара.

**Свёрнуто (64 px).** Остаются значки разделов, поиск, главное действие и аватар. Группы разделены тонкой чертой, подзаголовки, проекты и история скрыты. Из счётчиков видны только «требующие внимания».

**Телефон (до 700 px).** Панель выезжает слева поверх содержимого, закрывается крестиком, Esc, тапом по фону и выбором раздела.

**Счётчики.** Обычный — серые цифры. «Требует внимания» — оранжевая плашка. Свёрнутая группа показывает сумму таких счётчиков в заголовке, чтобы новое не терялось.

**Клавиатура.** `⌘K` или `/` — поиск. `[` — свернуть панель. `C` — главное действие. `⌥1…⌥9` — раздел по номеру. `↑ ↓ Home End` — по строкам панели. `← →` — свернуть или раскрыть группу.

## Что приложение передаёт данными

```ts
brand: { label, logo }
primaryAction?: { label, icon, shortcut, onSelect }
groups: [{ id, title?, kind: "sections" | "list", collapsible?, defaultCollapsed?, limit?,
           items: [{ id, label, icon?, badge?: { value, label, tone?: "attention" } }] }]
activeId, onSelect(item)
account: { name, initials?, email?, plan?, menu: MenuEntry[] }
onSettings?, header?, children, storageKey?
```

- `kind: "sections"` — разделы со значками, видны в свёрнутой панели.
- `kind: "list"` — данные пользователя (чаты, проекты): обрезка «…», в свёрнутой панели скрыты.
- `limit` — сколько строк показать до «Показать ещё N» (для длинной истории).
- `storageKey` — свёрнутость панели и групп запоминается между заходами.

Приложение без чатов просто не передаёт группу истории — больше ничего менять не нужно.

## Перед переносом в AppShell

Вернуть из `AppShell` ссылки (`href`, `linkComponent`), подписи для локализации (`labels`) и модальное поведение шторки (`useModalBehavior`). В прототипе они упрощены.

# Песочница: три варианта композиции

Исследование по просьбе Юрия после сравнения рабочего экрана с ChatGPT. Это варианты для выбора, а не изменение опубликованного визуального контракта.

- `?v=a` — «Фокус»: узкая навигация, поле в центре, журнал по запросу.
- `?v=b` — «Кабинет»: постоянная история, крупное приглашение и примеры начала диалога.
- `?v=c` — «Студия»: чат и журнал на отдельных поверхностях, без общей сетки перегородок.

Запуск из корня репозитория: `python3 -m http.server 8732 --bind 127.0.0.1`, затем http://localhost:8732/explorations/sandbox/ . Нужны собранные `packages/tokens/dist/tokens.css`; палитра подключается оттуда. Значки — локальные Phosphor, сфера — общий скрипт набросков. Исторические наброски не изменены.

На странице работают переключение вариантов и темы, история, журнал, инструкция, настройки и демонстрационный диалог. Модель не вызывается, микрофон не записывает звук, вложение — пример. Выбор настройки меняет только подпись в макете. Это самостоятельный визуальный прототип; интеграция настоящего чата остаётся задачей владельца Agent Chat SDK.

Предлагаемые отличия от текущего контракта: более крупные радиусы поля (18–24 px), спокойные поверхности вместо рамок, другая композиция пустого состояния. На основные пакеты и приложения эти изменения не перенесены.

`?app=1` скрывает панель выбора; Esc возвращает её. Снимки трёх вариантов — в `previews/`.

## Выбранное направление: «Студия»

Юрий выбрал «Студию» для песочницы. ChatGPT был сравнением качества, а не образцом для копирования. Фирменная сфера остаётся оранжевой во всех вариантах и темах.

`?v=c&state=dialog` открывает заполненный диалог, `?v=c&state=working` — ответ в процессе. Переключатели состояний находятся над приложением. История сообщений и журнал прокручиваются отдельно; поле ввода остаётся внизу. Журнал фильтруется по вызовам модели, параметры запроса раскрываются. В режиме работы агента есть оранжевая сфера и действующая кнопка остановки.

Сценарий и журнал демонстрационные. Диалог можно продолжить локально; API провайдеров не вызывается. Снимки состояний: `previews/studio-dialog.png`, `studio-working.png`, `studio-dialog-light.png`, `studio-dialog-mobile.png`.

# Сайдбар · вариант B — структура Gemini в характере «Одуванчика»

Запуск из корня YKDesignSystem:

```sh
pnpm --dir apps/showcase exec vite ../../explorations/sidebar-b --config ../../explorations/sidebar-b/vite.config.mjs --host 127.0.0.1 --port 5282
```

http://127.0.0.1:5282/ — справа вверху переключатели «Тариф / Почта / Только имя», «Раскрыто / Свёрнуто / Телефон» и тема. Переключатель «Чат и разделы / Только разделы» показывает агентское приложение и обычный кабинет онлайн-школы; во втором режиме есть выключатель кнопки «Создать». Параметры адреса: `?kind=sections`, `?primary=none`, `?theme=dark`, `?mode=rail`, `?account=plan|email|name`, `?frame&open` (телефон с открытой панелью).

Каркас — `ChatSidebarShell.tsx` + `chat-sidebar.css`, демо-данные — `main.tsx`.

## Что жёстко одинаково (приложение не трогает)

**Композиция.** Панель 272 px (свёрнутая 68 px) на фоне `--yk-sidebar`, рабочая область — приподнятая скруглённая поверхность `--yk-radius-studio-panel`, как в AppShell.

**Верх (не прокручивается).**
- Строка: значок и название слева, справа «Поиск» и «Свернуть».
- Под ней главное действие на всю ширину. Это «чернила», как главная кнопка системы, а не серая плашка Google. Справа подсказка клавиш моноширинным шрифтом.
- Когда середину прокрутили, под верхом появляется тонкая линия.

**Середина (прокручивается только она).**
- Разделы со значками, высота 40 px. Выбранный — серая плашка `--yk-surface-3`, значок `fill`.
- Группы с подписью моноширинным капсом и числом строк. Кнопка «+» появляется при наведении. Группу можно свернуть стрелкой.
- Строки чатов без значков, длинное название обрезается «…». При наведении справа «…» с меню действий.
- Фирменные приметы на своих местах: оранжевая сфера — «агент сейчас отвечает в этом чате», точка — «есть непрочитанное». Других акцентов нет.

**Низ (не прокручивается).** Аватар и имя, справа шестерёнка. Клик по аватару — меню аккаунта. Вторая строка под именем:
- по умолчанию — почта обычным шрифтом, серым;
- если приложение передало тариф — тариф моноширинным капсом вместо почты;
- нет ни почты, ни тарифа — имя одно, по центру аватара по вертикали.

**Свёрнуто.** Остаются кнопка «Развернуть», главное действие квадратом-«чернилами», значки разделов на тех же высотах, аватар внизу. Группы, поиск и шестерёнка скрыты: поиск — по ⌘K, настройки — через меню аккаунта.

**Телефон до 700 px.** Кнопка в шапке открывает ту же раскрытую панель слева поверх содержимого, вместо «Свернуть» — крестик. Закрывают её Escape, нажатие на фон и выбор пункта. Фокус при открытии встаёт на саму панель, а не на первую кнопку.

## Что в стандарте необязательно

Одна и та же панель подходит и агентским приложениям, и обычным: кабинетам, админкам, планировщикам. Обязательны только `brand`, `account` и хотя бы один набор разделов. Всё остальное приложение просто не передаёт, и эта часть исчезает без пустого места:
- нет `primaryAction` — разделы поднимаются сразу под строку с названием;
- нет `onSearch` — нет значка поиска;
- нет `groups` (история, проекты) — ничего «чатового»: ни сферы, ни точек, ни списков без значков;
- `sections` — разделы без подписи; `sectionGroups` — группы разделов со значками и подписью («Основное», «Обучение»). В свёрнутом виде подписи групп заменяет короткая черта между значками;
- `email` и `plan` — см. «Низ».

## Что приложение передаёт данными

| Свойство | Что это |
|---|---|
| `brand` | название и значок |
| `primaryAction` | подпись, значок, действие, подсказка клавиш |
| `sections[]` | разделы без подписи группы: значок, подпись, `active`, счётчик |
| `sectionGroups[]` | группы разделов: подпись и разделы со значками |
| `groups[]` | группы: подпись, строки (`active`, `working`, `unread`, меню), «+», `limit` до «Показать все», `collapsible` |
| `account` | имя, буквы, `email` и необязательный `plan`, пункты меню, действие шестерёнки |
| `onSearch` | поиск; без него значок не показывается |
| `header`, `children` | шапка и содержимое рабочей области |
| `collapsed` / `onCollapsedChange` | состояние панели |

Число групп и их смысл (проекты, «Сегодня», «Вчера») решает приложение. Как выглядит группа — решает система.

## Отличия от нынешнего AppShell

Новые части — главное действие, поиск в верху, группы со строками без значков, тариф и шестерёнка внизу. Разделы стали 40 px вместо 48 px: иначе длинной истории чатов не хватает места. Остальное поведение совпадает с [NAVIGATION.md](../../NAVIGATION.md).

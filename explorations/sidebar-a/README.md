# Сайдбар · вариант A — плоский, как Gemini

Плоская панель на фоне `--yk-sidebar`, без карточки и рамок. Рабочая область отличается от неё только цветом фона. Тонкая линия появляется только тогда, когда список уезжает под верх или под низ.

Запуск из корня YKDesignSystem:

```sh
apps/showcase/node_modules/.bin/vite explorations/sidebar-a --config explorations/sidebar-a/vite.config.mjs --host 127.0.0.1 --port 5281
```

http://127.0.0.1:5281/ — переключатели типа приложения, состояния и вида аккаунта в верхней строке. Тема — в настройках (шестерёнка внизу). Адрес можно задать сразу: `?view=collapsed&theme=dark`. Телефон с открытой панелью — `?frame&drawer`. Вид аккаунта — `?account=email|plan|name` (по умолчанию почта). Тип приложения — `?app=chat|sections`. Снимки: `node shoot.mjs` → `screenshots/`.

## Жёстко одинаково во всех приложениях

**Верх.** Логотип и название слева. Справа поиск и кнопка сворачивания. В свёрнутом виде остаются сворачивание и поиск друг под другом.

**Ведущий блок.** Главное действие в серой плашке, под ним разделы со значками. Он не прокручивается. Оба необязательны.

**Правило главного действия.** Главное действие есть только у приложения, где одно действие повторяется постоянно и главнее остальных, как «Новый чат». В обычных кабинетах и админках его нет, и разделы стоят сразу под верхом.

**Середина** — единственная прокручиваемая часть. В ней группы с мелкими подзаголовками моноширинным капсом. Длинные названия обрезаются «…», полное название показывается в подсказке.

Группы бывают двух видов, и вид задаёт приложение:
- **разделы** (`iconsWhenCollapsed`) — «Обучение», «Маркетинг», «Финансы» в кабинете. В свёрнутом виде остаются значками, без подзаголовков;
- **списки** — проекты, история чатов. В свёрнутом виде скрыты. Пункты без значка — строка чата.

Так один стандарт подходит и чату с агентом, и обычному кабинету, админке или планировщику.

**Низ.** Аватар, имя, под ним вторая строка, справа шестерёнка. Нажатие на аватар открывает меню аккаунта (`Menu` из ds-react). В свёрнутом виде остаётся только аватар, настройки доступны через меню.

Три вида нижнего блока:
- **«Почта»** — по умолчанию. Под именем почта. Приложение передаёт `email`, поле `show` можно не задавать.
- **«Тариф»** — под именем тариф. Приложение передаёт `plan` и `show: "plan"`. Только для приложений, где тарифы есть.
- **«Только имя»** — имя одно, по центру аватара. Приложение передаёт `show: "name"`.

Если для выбранного вида нет данных (например, `show: "email"` без почты), остаётся только имя.

**Размеры и поведение.** Ширина 264 px, свёрнутая 68 px. Строка 40 px, пункты в группах 36 px. Центр значков на x = 34 px в обоих видах, поэтому значки при сворачивании не прыгают. Выбранный пункт — плашка `--yk-surface-3` и значок `fill`, наведение — `--yk-surface-2`. Новое отмечается оранжевой точкой. Переход длится 180 мс. До 700 px панель открывается слева поверх содержимого, затемняет фон и закрывается по Escape, нажатию на фон, крестику или выбору пункта.

## Что приложение передаёт данными

```ts
brand          { label, logo }
primaryAction? { label, icon, onSelect }          // «Новый чат», «Создать»…; нет — блока нет
sections?      [{ id, label, icon, active, hasNew, onSelect }]
groups         [{ id, label, items: [...], visibleCount?, iconsWhenCollapsed? }]   // без icon — строка без значка
account        { name, initials?, email?, plan?, show?: "email" | "plan" | "name", menu: MenuEntry[] }   // show по умолчанию "email"
onSearch, onSettings
storageKey?    // запоминать свёрнутость
```

Если задан `visibleCount`, лишние пункты прячутся под «Ещё N». Если выбранный пункт спрятан, группа раскрывается сама.

Пока не настраивается, но стоит решить при внедрении: действия у строки чата («⋯» при наведении), счётчики у разделов (в `AppShell` уже есть `badge`), подписи для других языков.

## Тема — только в настройках

Светлая и тёмная тема меняются только в настройках: «Тема: Как в системе / Светлая / Тёмная», по умолчанию «Как в системе». Отдельной кнопки темы в интерфейсе нет: ни в сайдбаре, ни в шапке, ни быстрым пунктом в меню аккаунта. Шестерёнка внизу и пункт «Настройки» в меню аккаунта открывают настройки.

## Что в стандарте необязательно

Главное действие, разделы над группами, сами группы, почта и тариф, обработчик поиска. Обязательны только название с логотипом, имя аккаунта и его меню.

## Файлы

# «Студия»: композиция рабочего экрана

Утверждена Юрием для песочницы 22 октября 2026 года. Интерактивный образец — [explorations/sandbox](explorations/sandbox/README.md), заполненная переписка — `?v=c&state=dialog`, процесс ответа — `?v=c&state=working`.

Это собственный облик «Одуванчика». ChatGPT использовался как сравнение качества композиции, а не образец для копирования. Фирменные признаки сохраняются: оранжевая сфера, Phosphor regular, системный шрифт и моноширинные служебные метки.

## Геометрия

- Чат и журнал — отдельные поверхности без общей сетки рамок. Навигация 64 px, журнал 300 px, зазор 16 px. Панели скруглены на 20 px.
- Колонка переписки — до 730 px; текст 15–16 px, межстрочный интервал 1.8. Обычный текст не превращается в моноширинный.
- Сообщение человека расположено справа на `surface2`, радиус 16 px. Ответ агента идёт без пузыря; заголовки, абзацы и списки имеют собственные отступы.
- Поле чата имеет радиус 18 px, стоит внизу и не прокручивается вместе с перепиской. Микрофон — непосредственно перед отправкой; во время ответа отправка становится кнопкой «Стоп».
- Журнал и переписка прокручиваются независимо. Скроллбару отведён `scrollbar-gutter: stable` плюс 16 px свободного места до текста: одного gutter недостаточно при системных overlay-скроллбарах.
- На телефоне журнал открывается в `Sheet`: фокус внутри, Esc закрывает шторку и возвращает фокус к кнопке. Навигация не отнимает ширину переписки.

Это добавочные роли, они не меняют радиусы обычных карточек и полей. Фирменная сфера вне кнопки — оранжевая; внутри загрузочной кнопки цвет индикатора определяется контрастом кнопки.

## Пакеты 0.2.0

```tsx
import "@ykurilov/ds-tokens/tokens.css";
import "@ykurilov/ds-react/styles.css";
import { ScrollArea, StudioLayout } from "@ykurilov/ds-react";

// journalOpen/setJournalOpen — состояние приложения.
// chat — настоящий чат SDK; journal — события SDK или продуктового приложения.
<div style={{ height: "100dvh" }}>
  <StudioLayout header={header} navigation={navigation}
    inspector={{ title: "Журнал", content: journal,
      open: journalOpen, onClose: () => setJournalOpen(false) }}>
    {chat}
  </StudioLayout>
</div>;

// Для собственной прокручиваемой области, например журнала:
<ScrollArea label="События журнала">{events}</ScrollArea>;
```

`StudioLayout` принимает `header`, `navigation?`, `navigationLabel?`, `contentLabel?`, `inspector?`, `children` и стандартные свойства div. `inspector` содержит `title`, `content`, `open`, `onClose`. На компьютере журнал виден постоянно; `open` управляет мобильной шторкой (ширина до 700 px). В `header` приложение размещает кнопку открытия журнала.

Содержимое журнала монтируется один раз. При переходе между мобильной и настольной композицией оно перемонтируется; фильтры и данные хранить выше `StudioLayout`. `ScrollArea` передаёт ref DOM-элемента вызывающему коду, имеет доступное имя и по умолчанию `tabIndex=0`.

Корневому контейнеру требуется заданная высота. У flex/grid-предков — `min-height: 0`. Внутри основного слота — одна прокручиваемая лента и непрокручиваемый footer. Настоящий чат SDK сам управляет лентой, её ref и виртуализацией: его нельзя оборачивать во второй `ScrollArea`.

## Граница с SDK

`ds-react` содержит компоновку и область прокрутки, `ds-tokens` — размеры, палитру и радиусы (CSS, JS и Swift). Сам чат, реплики, потоковый ответ, модель, инструменты и журнал песочницы принадлежат Agent Chat SDK и его скину. Демонстрационные ответы и события HTML-макета в пакеты не переносятся.

В SDK используются настоящие события `model`/`tool` и доступные ему параметры; статические этапы из макета не становятся выдуманными событиями боевого журнала. Скин подключает `ds-*` как зависимости, без локальных копий сферы, палитры и компоновки.

Новые переменные: `--yk-radius-studio-panel`, `--yk-radius-composer`, `--yk-radius-message`, `--yk-studio-navigation-width`, `--yk-studio-inspector-width`, `--yk-studio-thread-width`, `--yk-studio-panel-gap`, `--yk-studio-scrollbar-gap`, `--yk-studio-body-size`, `--yk-studio-body-line-height`.
